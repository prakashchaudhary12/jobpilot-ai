JOBPILOT AUTHENTICATION AND SPEED UPDATE

1. Copy .env.example to .env.
2. Add:
   ADZUNA_APP_ID=7270e3c6
   ADZUNA_APP_KEY=YOUR_NEW_ADZUNA_KEY
   AI_PROVIDER=ollama
   OLLAMA_MODEL=llama3.2:3b

3. Install:
   python -m pip install -r requirements.txt

4. Run:
   streamlit run main.py

The app now includes local SQLite login/register/logout.
Database file: jobpilot_users.db

Important:
- This is suitable for local testing/small internal use.
- For public production deployment, use HTTPS, PostgreSQL, secure session management,
  email verification, password reset and rate limiting.
- Existing job/resume data may still be shared by old modules unless those modules are
  also changed to filter every record by the logged-in user id.
